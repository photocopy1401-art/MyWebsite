تابع کامل محاسبه کرایه؛ کد را خط‌به‌خط ببینید

function calculateFare(distance, pricePerKm) {
  // مرحله ۱: بررسی ورودی‌ها
  if (distance <= 0 || pricePerKm < 0) {
    return 0;
  }

  // مرحله ۲: محاسبه مبلغ پایه
  const baseFare = distance * pricePerKm;

  // مرحله ۳: برگرداندن نتیجه به جایی که تابع فراخوانی شده
  return baseFare;
}

// مرحله ۴: فراخوانی تابع با دو ورودی
const finalFare = calculateFare(12, 10000);

console.log(finalFare); // 120000
توضیح خط‌به‌خط:
۱. function calculateFare(distance, pricePerKm) تابعی به نام calculateFare می‌سازد که دو ورودی می‌گیرد: مسافت و نرخ هر کیلومتر.
۲. شرط if ورودی نامعتبر را بررسی می‌کند.
۳. متغیر baseFare حاصل‌ضرب مسافت در نرخ هر کیلومتر را نگه می‌دارد.
۴. دستور return نتیجه را از تابع بیرون می‌فرستد؛ اگر return نباشد، خروجی تابع به‌صورت پیش‌فرض undefined خواهد بود.
۵. در خط آخر تابع را با مقادیر ۱۲ و ۱۰۰۰۰ اجرا کرده‌ایم؛ بنابراین خروجی ۱۲۰۰۰۰ می‌شود.
اجرای همان تابع با ورودی دلخواه
مقدار ورودی بدهید و تابع را اجرا کنید.

۶. حلقه‌ها (Loops)

حلقه‌ها یک دستور را چند بار اجرا می‌کنند. وقتی با فهرستی از رانندگان یا سفارش‌ها روبه‌رو هستیم، حلقه‌ها بسیار مفیدند.

const drivers = ["علی", "رضا", "محمد", "حسین"];

for (let i = 0; i < drivers.length; i++) {
  console.log(drivers[i]);
}
توضیح: i شماره جایگاه است و از صفر شروع می‌شود. drivers.length تعداد اعضای آرایه را می‌دهد. با هر دور حلقه، i++ آن را یک واحد افزایش می‌دهد.

کد قابل استفاده مجدد

۷. توابع (Functions)

تابع مجموعه‌ای از دستورهاست که برای انجام یک کار مشخص تعریف می‌شود. تابع می‌تواند ورودی بگیرد و با return نتیجه برگرداند.

function calculatePrice(distance) {
  const pricePerKm = 10000;
  const totalPrice = distance * pricePerKm;
  return totalPrice;
}

const tripPrice = calculatePrice(12);
console.log(tripPrice); // 120000
اجزای تابع: function کلمه تعریف تابع است؛ calculatePrice نام تابع؛ distance پارامتر ورودی؛ و return نتیجه را به محل فراخوانی برمی‌گرداند.
تابع را در این مثال کامل می‌بینید: ورودی تابع distance است؛ تابع نرخ هر کیلومتر را تعیین می‌کند، مبلغ را حساب می‌کند و با return برمی‌گرداند. سپس مقدار برگشتی در متغیر tripPrice ذخیره و نمایش داده می‌شود.
function calculatePrice(distance) {
  const pricePerKm = 10000;
  const totalPrice = distance * pricePerKm;

  return totalPrice;
}

// اجرای تابع
const tripPrice = calculatePrice(8);

// استفاده از نتیجه
console.log("کرایه:", tripPrice); // 80000

نتیجه اینجا نمایش داده می‌شود.

  if (origin === "" || destination === "") {
    // نمایش پیام خطا
  } else {
    // آماده‌سازی درخواست
  }
});

ذخیره در مرورگر

۱۳. LocalStorage؛ ذخیره اطلاعات در مرورگر

LocalStorage امکان ذخیره داده‌های متنی را در مرورگر فراهم می‌کند؛ داده‌ها پس از بستن مرورگر نیز معمولاً باقی می‌مانند، مگر اینکه پاک شوند.

// ذخیره
localStorage.setItem("lastDestination", "فرودگاه");

// خواندن
const destination = localStorage.getItem("lastDestination");

// حذف
localStorage.removeItem("lastDestination");
سه متد اصلی: setItem ذخیره می‌کند؛ getItem می‌خواند؛ removeItem یک مورد را حذف می‌کند. برای پاک‌کردن همه موارد همان وب‌سایت از clear() استفاده می‌شود.
ذخیره آخرین مقصد در همین مرورگر
وضعیت ذخیره‌سازی نمایش داده می‌شود.
اطلاعات حساس مانند رمز عبور، اطلاعات بانکی یا توکن‌های حساس را بدون طراحی امنیتی مناسب در LocalStorage ذخیره نکنید. این ذخیره‌سازی به سرور منتقل نمی‌شود.

کاربرد در محصول: نگهداری ترجیح‌های ظاهری، آخرین مقصد، زبان انتخابی یا حالت روشن/تاریک. برای داده‌های حساس و همگام‌سازی بین دستگاه‌ها باید راهکار سمت سرور در نظر گرفت.

ارتباط با سرور

۱۴. Fetch API؛ دریافت اطلاعات از سرور

در برنامه واقعی، اطلاعات کاربران، رانندگان، قیمت و وضعیت سفر معمولاً از API سرور دریافت می‌شود. Fetch API برای ارسال درخواست HTTP و دریافت پاسخ به کار می‌رود.

fetch("https://jsonplaceholder.typicode.com/posts/1")
  .then(response => {
    if (!response.ok) throw new Error("پاسخ سرور ناموفق بود");
    return response.json();
  })
  .then(data => {
    console.log(data.title);
  })
  .catch(error => {
    console.log("خطا:", error.message);
  });
توضیح: fetch() درخواست را ارسال می‌کند. response.json() بدنه پاسخ را به داده JavaScript تبدیل می‌کند. then() ادامه کار پس از آماده‌شدن پاسخ را مشخص می‌کند و catch() خطاهای شبکه یا خطاهای پرتاب‌شده را مدیریت می‌کند.
دریافت یک مطلب از API آزمایشی
برای اجرای این بخش اتصال اینترنت لازم است.
این دمو از API عمومی آزمایشی استفاده می‌کند و برای اجرا به اینترنت نیاز دارد. برای دریافت داده واقعی سفر باید API اختصاصی و مجوز دسترسی به آن وجود داشته باشد.

کاربرد در محصول: دریافت قیمت، فهرست رانندگان، ثبت سفارش، بارگذاری تاریخچه و ارسال وضعیت پرداخت به سرور.

۱۵. خطایابی (Debugging)

خطایابی یعنی پیدا کردن علت درست کار نکردن برنامه و اصلاح آن. ابزارهای توسعه مرورگر کمک می‌کنند مقدار متغیرها، خطاها و روند اجرای کد را بررسی کنیم.

const distance = 12;
const pricePerKm = 10000;

console.log("مسافت:", distance);
console.log("هزینه هر کیلومتر:", pricePerKm);

const totalPrice = distance * pricePerKm;
console.log("هزینه نهایی:", totalPrice);

مراحل بررسی خطا در مرورگر

  1. فایل را در Chrome یا مرورگر دیگری باز کنید.
  2. کلید F12 را بزنید.
  3. در بخش Console پیام‌های خطا را بخوانید.
  4. در بخش Sources می‌توانید اجرای کد را مرحله‌به‌مرحله متوقف و بررسی کنید.
نمونه محاسبه و بررسی خروجی
خروجی در این قسمت و جزئیات در Console مرورگر نمایش داده می‌شود.

کاربرد در محصول: بررسی علت محاسبه اشتباه، پیدا کردن خطای فرم، تشخیص پاسخ ناموفق API و بررسی وضعیت متغیرها.

ترکیب مباحث

پروژه پایانی: ساخت فرم ساده درخواست سفر

در این تمرین چند مفهوم را کنار هم قرار می‌دهیم: متغیر، شرط، تابع، شیء، رویداد، DOM و فرم. این پروژه صرفاً یک شبیه‌سازی سمت مرورگر است و سفر واقعی ثبت نمی‌کند.

سامانه آموزشی درخواست سفر
پس از تکمیل اطلاعات، نتیجه اینجا نمایش داده می‌شود.

کد کامل تابعی که در پروژه استفاده شده است

function calculatePrice(distance) {
  const pricePerKm = 10000;
  return distance * pricePerKm;
}
ارتباط تابع با پروژه:
در رویداد ارسال فرم، مقدار مسافت از ورودی خوانده می‌شود. سپس دستور calculatePrice(distance) تابع را اجرا می‌کند. عدد برگشتی در ویژگی price شیء سفر قرار می‌گیرد. در پایان، DOM مقدار را به کاربر نشان می‌دهد. به این ترتیب تابع فقط یک قطعه کد جدا نیست؛ بخشی از جریان واقعی اجرای برنامه است.

منطق پروژه به زبان ساده

  1. فرم اطلاعات مسافر، مبدأ، مقصد و مسافت را می‌گیرد.
  2. رویداد submit ارسال فرم را تشخیص می‌دهد.
  3. مقادیر ورودی در متغیرها قرار می‌گیرند.
  4. شرط‌ها خالی نبودن فیلدها و معتبر بودن مسافت را بررسی می‌کنند.
  5. تابع calculatePrice مسافت را دریافت و مبلغ را برمی‌گرداند.
  6. یک شیء اطلاعات سفر را نگهداری می‌کند.
  7. DOM نتیجه را در صفحه نمایش می‌دهد.
یادگیری فعال

تمرین‌های پیشنهادی

  1. متغیر مقصد را تغییر دهید و مقدار جدید را در صفحه نمایش دهید.
  2. شرطی بنویسید که برای مسافت بیشتر از ۲۰ کیلومتر پیام جداگانه نشان دهد.
  3. یک راننده جدید به آرایه رانندگان اضافه کنید.
  4. برای شیء سفر یک ویژگی به نام paymentStatus اضافه کنید.
  5. با یک رویداد کلیک، وضعیت سفر را از «در انتظار راننده» به «راننده پیدا شد» تغییر دهید.
  6. آخرین مقصد را در LocalStorage ذخیره کنید و پس از بازکردن دوباره فایل آن را بخوانید.
  7. در پروژه پایانی، مبلغ را با تابعی جداگانه محاسبه کنید.
